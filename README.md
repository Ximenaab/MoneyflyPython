## Pasos para usar el proyecto

## 1.Clonar el repositorio
git clone https://github.com/ximenaab/MoneyflyPython.git
cd MoneyFly

## 2.Crear y activar entorno virtual
py -m venv .venv
source .venv/Scripts/activate

## 3.Ejecutar la aplicacion
py src/main.py
